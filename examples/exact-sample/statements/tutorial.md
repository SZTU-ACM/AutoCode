# Exact Sample 题解

## 思路概述

直接读入数组长度 `n` 与全部 `n` 个整数，使用 64 位有符号整数（`long long`）累加所有元素即可。

## 正确性说明

由数据范围 `1 <= n <= 2 * 10^5` 与 `-10^9 <= a_i <= 10^9` 可知，前缀和及最终答案的绝对值至多为 `2 * 10^{14}`，严格落在 64 位整数范围 `[-9 * 10^{18}, 9 * 10^{18}]` 内；若误用 32 位 `int` 会在大数场景下溢出出错。

## 复杂度分析

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(1)$（流式累加无需保存整个数组）。
