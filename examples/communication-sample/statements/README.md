# Communication Sample

## 时间限制与空间限制

- 时间限制：2 秒（两阶段总计）
- 空间限制：256 MB

## 题目背景（可选）

本题展示 AutoCode 对两阶段（Run-Twice）通信题题面与协议的推荐写法。

## 题目描述

Alice 持有一个 4 比特整数 $X$（$0 \le X \le 15$），她需要将其编码为一段仅包含 `0` 与 `1` 的二进制字符串 $S$，并通过一条可能翻转**至多 1 个比特**的噪声信道发送给 Bob。

Bob 只能看到经过信道传输后的二进制字符串 $S'$（长度与 $S$ 相同，至多有 1 位与 $S$ 不同），他需要准确还原出原始整数 $X$。

## 输入格式

本题为两阶段运行（Run-Twice）通信题，你的程序会在两个**物理隔离的独立进程**中先后运行两次：

- **第一阶段（编码 / Alice）**：
  - 第一行是一个字符串 `first`。
  - 第二行包含两个整数 `mode` 与 $X$（`mode` $\in \{0, 1\}$，$0 \le X \le 15$），其中 `mode = 0` 表示无噪信道，`mode = 1` 表示信道最多翻转 1 个比特。
- **第二阶段（解码 / Bob）**：
  - 第一行是一个字符串 `second`。
  - 第二行是经过信道传输后的二进制字符串 $S'$。

## 输出格式

- **第一阶段**：输出一行非空二进制字符串 $S$，仅由字符 `0` 和 `1` 组成，且满足长度 $|S| \le 12$。
- **第二阶段**：输出一行一个整数 $X'$，表示还原出的整数。

## 通信协议

- 通信模式：`run_twice`（两阶段进程隔离，严禁通过文件、环境变量或共享内存跨阶段传递状态）。
- 通信预算上限：
  - 最大比特数 `max_bits = 12`（即 $|S| \le 12$）
  - 最大字节数 `max_bytes = 2`（$\lceil |S| / 8 \rceil \le 2$）
  - 最大轮次 `max_rounds = 2`
- 信道模型：
  - 当 `mode = 0` 时，$S' = S$（无噪信道）。
  - 当 `mode = 1` 时，通信裁判会选择任意一个位置翻转（或保持不变），保证 $S$ 与 $S'$ 的汉明距离不超过 $1$。
- 判分规则：
  - 若第一阶段输出为空、含非 `0/1` 字符、超出 12 比特预算或有多余输出，判为 `PE` 或 `WA`。
  - 若第二阶段输出 $X' = X$ 且两阶段均未超时/超内存/运行错误，判为 `AC`；否则判为 `WA`。

## 子任务

- **Subtask 1（40 分）**：`mode = 0`（无噪信道）。
- **Subtask 2（60 分，依赖 Subtask 1）**：`mode = 1`（至多 1 比特翻转）。

## 样例

下面展示一次两阶段通信的完整 transcript（假设 $X = 10 = (1010)_2$，信道翻转了第 1 位）：

```text
[Pass 1 input]
first
1 10

[Pass 1 output (Alice)]
111000111000

[Channel (flip index 0)]
011000111000

[Pass 2 input (Bob)]
second
011000111000

[Pass 2 output (Bob)]
10
```

## 说明

在样例中，Alice 将 $X = 10$ 的 4 个二进制位各重复 3 次，发送 12 比特 `111000111000`。即使信道翻转了第 1 个比特变成 `011000111000`，Bob 对每 3 位取多数投票仍能准确还原出 `(1010)_2 = 10`。
